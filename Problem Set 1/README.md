# ECON 5200 Problem Set 1: The Measurement Audit

## Average Basket Value Audit

The dashboard made the increase in average basket value look bigger than it actually was. After excluding B2B transactions, the mean shows a 1.55% increase from Year 1 to Year 2.

The strongest objection was whether B2B transactions should actually be excluded. Since B2B transactions are still real sales, excluding them only makes sense if the dashboard is supposed to measure consumer basket value. I compared B2B and consumer transactions separately. There were 20,250 consumer transactions and only 300 B2B transactions, but the average B2B basket was much higher, at 238.62 dollars compared with 60.80 dollars for consumers. B2B transactions made up about 5.5% of total revenue.

This suggests that B2B transactions are a small but very different group that can affect the overall mean. I am fairly confident in the result, but before fully relying on it, I would still want to check if the B2B rule correctly separates B2B transactions from regular consumer transactions.
